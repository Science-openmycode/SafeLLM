03

分段理解每一层保护

选择一个步骤，查看它改变了什么、密钥在哪里、服务端能看到什么。

CLIENT ONLY

真实 token ID 被秘密置换

x̃ᵢ = τ(xᵢ)

原 tokenizer 与完整对话历史只在可信客户端使用。置换保持序列长度，但改变每一个词表坐标。默认模式是确定性置换；M1 是可选扰动。

客户端持有τ、τ⁻¹服务端看到x̃不发送原文、明文 IDs

OFFLINE TRANSFORMATION

输入、输出词表与权重同步变化

W̃ₑ = Π(Wₑ + αₑEₑ)P　·　W̃ₕ = Q(Wₕ + αₕEₕ)Πᵀ

Embedding 与 LM Head 使用同一个词表置换 Π，并分别加入论文形式的高斯噪声。这样私有输入能进入模型，生成结果也落在同一个私有词表中。

隐藏词表对应关系噪声削弱权重匹配同步输入与输出坐标

COVARIANT COORDINATES

P/Q 让隐藏状态在扩维坐标中传播

P ∈ ℝᵈˣᴰ　·　Q ∈ ℝᴰˣᵈ　·　PQ = I

相邻算子成对吸收 P 与 Q。Attention 同步处理 Q/K/V/O、GQA 与 RoPE；FFN 同步处理 Gate/Up/Down；RMSNorm 使用经过证明的精确度量修正。

Attentionhead/block permutationFFNpermutation + scalingResidual坐标一致

MODEL SERVER

服务端全程在私有坐标中计算

f̃φ(θ)(τ(x)) → τ(y)

服务端不加载原始模型，也不持有在线逆置换。Prefill、逐 token decode 与 KV Cache 都保存私有坐标；日志只记录身份、token 数量和耗时。

请求private input_ids模型private checkpoint响应private output_ids

CLIENT ONLY

每个私有输出 token 到达后立即恢复

yᵢ = τ⁻¹(ỹᵢ)

SSE 返回私有输出 ID。客户端检查 request ID 和序号，执行逆置换，再用原 tokenizer 增量解码。自然语言答案不会在模型服务器生成或记录。

04

谁能看到什么

安全边界来自密钥和模型包的分离，而不是把所有内容放在同一台服务器。

客户端
  • 真实 prompt 与对话历史
  • 原 tokenizer
  • τ 与 τ⁻¹
  • 最终自然语言回答
网络请求
  • model_id / key_id
  • 混淆 input_ids
  • 生成参数
  • 混淆 output_ids
模型服务器
  • 混淆 checkpoint
  • 私有 token 流
  • KV Cache 私有坐标
  • token 数与耗时
服务器不应持有
  • 原始模型权重
  • 真实 prompt
  • τ / τ⁻¹
  • 离线转换种子

该边界表示工程上不把明文和逆置换材料交给模型服务，并通过已实现攻击进行验证；它不等同于对任意恶意服务器的绝对密码学不可恢复声明。
