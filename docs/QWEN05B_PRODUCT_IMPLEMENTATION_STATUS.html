1. 论文方法要执行的完整数据流

1.1 客户端输入

客户端保留原始 tokenizer、对话历史、词表置换 τ\tau 和逆置换 τ−1\tau^{-1}。用户输入消息 mm 后，客户端先执行 Qwen Chat Template：

x=Tokenizer⁡(ChatTemplate⁡(m,history)). x=\operatorname{Tokenizer}\bigl(\operatorname{ChatTemplate}(m,\text{history})\bigr).

默认 privacy_mode=permutation 时直接置换 token ID：

x̃i=τ(xi). \widetilde{x}_i=\tau(x_i).

可选 privacy_mode=rmdp 时，先使用 M1 指数机制得到 x′ix'_i，再置换：

Pr⁡[x′i=j∣xi]=exp⁡(−ϵ1d(xi,j)/2)∑k∈𝒱exp⁡(−ϵ1d(xi,k)/2),x̃i=τ(x′i). \Pr[x'_i=j\mid x_i] =\frac{\exp\!\left(-\epsilon_1 d(x_i,j)/2\right)} {\sum_{k\in\mathcal V}\exp\!\left(-\epsilon_1 d(x_i,k)/2\right)}, \qquad \widetilde{x}_i=\tau(x'_i).

本实现按论文单 token 置换距离取 d(i,i)=0d(i,i)=0、d(i,j)=2d(i,j)=2。因此原 token 权重为 1，其余每个词表项权重为 e−ϵ1e^{-\epsilon_1}。长序列采用逐 token 组合，并在客户端保存本地隐私账本。

1.2 词表、Embedding 与 LM Head

设置换矩阵为 Π\Pi，明文 Embedding 和 Head 为 We,WhW_e,W_h。加入论文噪声后：

We⋆=We+αeℰe,Wh⋆=Wh+αhℰh. W_e^\star=W_e+\alpha_e\mathcal E_e, \qquad W_h^\star=W_h+\alpha_h\mathcal E_h.

模型转换使用：

W̃e=ΠWe⋆Pe,W̃h=QhWh⋆Π⊤. \widetilde W_e=\Pi W_e^\star P_e, \qquad \widetilde W_h=Q_hW_h^\star\Pi^\top.

客户端发送 τ(x)\tau(x)，服务器模型的 Embedding 行和 LM Head 输出列使用同一 Π\Pi。生成的私有 token 会作为下一步 decode 输入继续回灌，不在服务器上逆置换。

1.3 P/Q 扩维

明文残差维度为 dd，私有维度为 D=d+2hD=d+2h：

P∈ℝd×D,Q∈ℝD×d,PQ=Id. P\in\mathbb R^{d\times D}, \qquad Q\in\mathbb R^{D\times d}, \qquad PQ=I_d.

若明文行向量为 xx，私有坐标为 z=xPz=xP。相邻线性层分别乘 PP 和 QQ， 使中间坐标抵消。实现保留论文 Algorithm 1 的共享 Init 和独立 DjD_j，没有 换成自行设计的可逆方阵。

1.4 RMSNorm 修正式

论文标量 κ\kappa 对一般矩形 PP 不能保证逐输入等价。精确实现由 PQ=IdPQ=I_d 构造公开派生度量：

G=QQ⊤,zGz⊤=xPQQ⊤P⊤x⊤=xx⊤. G=QQ^\top, \qquad zGz^\top=xPQ Q^\top P^\top x^\top=xx^\top.

私有 RMS 使用：

PrivRMS⁡(z)=zzGz⊤/d+ε. \operatorname{PrivRMS}(z) =\frac{z}{\sqrt{zGz^\top/d+\varepsilon}}.

该修改保留 P/Q 扩维和所有论文结构变换，只替换无法满足函数等价的标量归一化。 完整推导见 docs/paper_errata/E15_RMSNorm_Scalar_Kappa_Is_Not_Exact.md。

1.5 Qwen Attention

Qwen2.5-0.5B 每层有 14 个 Q head 和 2 个 KV head，即每个 KV head 对应 7 个 Q head。实现对这 7 个 Q head 与对应 KV head 同步置换。Q/K、V/O 的变换为：

W̃q=QqWqRqkHqkZ,W̃k=QkWkRqkHqk−1Z, \widetilde W_q=Q_qW_qR_{qk}H_{qk}Z, \qquad \widetilde W_k=Q_kW_kR_{qk}H_{qk}^{-1}Z,

W̃v=QvWvUvo,W̃o=Uvo−1WoPo. \widetilde W_v=Q_vW_vU_{vo}, \qquad \widetilde W_o=U_{vo}^{-1}W_oP_o.

其中 RqkR_{qk} 是 Q/K head 同步置换，HqkH_{qk} 是逐 head 缩放，ZZ 是二维 RoPE block 置换。Qwen 不同二维块使用不同频率。只有 ZR(t)=R(t)ZZR(t)=R(t)Z 时置换 才保持函数，而跨频率块一般不满足该式。因此：

  • paper-default 保留论文 β=8\beta=8，作为有损论文参数实验；
  • 无噪声函数等价配置使用 β=1\beta=1；
  • GQA、head permutation、Q/K 缩放、V/O 变换仍全部启用。

推导见 docs/paper_errata/E16_RoPE_Block_Permutation_Is_Not_Function_Preserving.md。

1.6 FFN、Residual 与 KV Cache

Qwen SwiGLU 的 Gate 和 Up 使用同一个中间维置换 SS 与缩放 DfD_f：

W̃gate=QgWgateSDf,W̃up=QuWupSDf, \widetilde W_{gate}=Q_gW_{gate}SD_f, \qquad \widetilde W_{up}=Q_uW_{up}SD_f,

W̃down=Df−1S⊤WdownPout. \widetilde W_{down}=D_f^{-1}S^\top W_{down}P_{out}.

Attention 和 FFN 的主支路、Residual 支路在相加前使用同一个私有残差坐标。 Prefill 产生的私有 K/V Cache 直接用于 decode，服务器不恢复明文坐标。

1.7 服务端输出与客户端恢复

服务端返回私有 token：

ỹt=f̃(x̃,ỹ<t). \widetilde y_t=\widetilde f(\widetilde x,\widetilde y_{<t}).

客户端逐 token 执行：

yt=τ−1(ỹt),textt=Tokenizer.decode⁡(y≤t). y_t=\tau^{-1}(\widetilde y_t), \qquad \text{text}_t=\operatorname{Tokenizer.decode}(y_{\le t}).

SDK 对累计文本做前缀差分，SSE 每次只打印新增文本。

cd E:\AloePri

uv run aloepri rmdp-budget `

9. 结论

当前 0.5B 已经具备真实客户端输入、Chat Template、本地分词、token ID 置换、 私有 HF checkpoint、SSE 生成、客户端逆置换和正常回答的完整产品闭环。服务器包 不含在线 key、P/Q、转换种子、原 tokenizer 和原权重，抓包中不出现明文或明文 token 序列。

当前不能发布为“同时满足论文效用和甲方隐私门槛”的产品：无噪声 v25 保持问答 但不能抵抗权重匹配；论文强噪声 v22 的当前 VMA 数值合格，但 20 条问答 0/20 完全一致。按照既定停止条件，正式结论保持 NO-GO，旧 v15、Toy 结果和代理攻击 均未用于当前 checkpoint 验收。
